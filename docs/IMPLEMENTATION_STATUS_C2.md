# 电影印记：C2 作品匹配进度

日期：2026-08-01  
状态：C2 作品匹配、按日壁纸及需求复核收尾已完成

## 已完成

- 将 `#系列/作品` 定义为可选输入线索，不建立全局标签树；
- IndexedDB 从 v1 升级到 v2，增加 `works` 存储；
- 新记录会先建立 `identity_status: local_only` 的稳定 Work，并与感想记录原子写入；
- 旧记录打开时会补建稳定 Work，不改写原文；
- 系列速记的完整标签与最后一段作品名会进入 Work 别名，供后续召回候选；
- `/` 只表达输入时的系列从属关系；本地成品标题只显示末段作品名，确认 Bangumi 条目后改用条目的规范标题与 `https://bangumi.tv/subject/{id}` 链接；
- 增加同源 `/api/bangumi/search` 代理契约：
  - 只向正式 `/v0/search/subjects` 请求动画与真人条目；
  - 最多返回三个经过裁剪的候选；
  - 默认排除 NSFW；
  - 6 秒超时、24 小时内存缓存，最多保留 100 个查询；
  - User-Agent 与可选令牌只存在服务端；
  - 未配置或上游失败时明确降级，本地记录不受影响。
- 使用用户授权的 `qiankunyi/movie-imprint/0.1` 作为默认 User-Agent；显示名称为“钱坤一”；
- 完成记录后在后台检索，不阻断本地保存和返回首页；
- 首页显示“正在匹配作品／待确认作品／已匹配 Bangumi”状态；
- 详情页显示最多三个候选，以及“都不是，保留本地作品”和“重新匹配”；
- 用户确认后只更新稳定 Work 的标准标题、原名、类型、年份、别名与 `external_refs`，原始感想不变；
- 离线或上游失败时显示降级提示，允许稍后重试。
- 增加同源 `/api/bangumi/image` 图片代理：
  - 只接受正整数 subject ID，并调用正式条目图片接口；
  - 重定向目标必须是 `https://lain.bgm.tv`；
  - 只接受 JPEG、PNG、WebP，单张上限 6 MB；
  - 不把 Bangumi 图片地址暴露给浏览器；
  - 服务端内存最多缓存 12 张并在一天后刷新，响应带一天浏览器缓存策略；
- 从已确认 Bangumi ID 的作品中按本地日期稳定选择今日壁纸，并把当天选择写入 `meta`；
- 同一天新增作品不会突然换图；次日才重新稳定选择；
- Service Worker 最多缓存 12 张同源壁纸，断网刷新时优先恢复缓存；
- 没有已匹配作品、无封面或图片失败时继续使用现有中性壁纸；
- 首页显示“今日壁纸 · 作品名”和“来源 Bangumi”，来源链接使用规范化条目 URL；
- 封面只用于私人应用界面，不进入原始记录、导出资产或 GitHub 同步数据。
- 首页二级偏好层支持换一张、固定、恢复按日轮换与关闭作品壁纸，偏好只写入本机；
- 已确认作品在详情中提供“修改匹配”，取消或搜索失败时保留原有稳定 ID；
- Service Worker 壁纸缓存使用七天刷新期限、12 张容量上限和断网过期缓存兜底；服务端图片内存缓存一天后刷新；
- “完成”先持久化 `raw_only_confirmed` 原文记录，再进入后台整理；关闭自动整理时会保留该状态，并可从详情稍后整理。
