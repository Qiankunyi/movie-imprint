# 下一开发窗口启动指令

请先完整阅读 `docs/DEVELOPMENT_HANDOFF_V2.md`，并按其中列出的优先级阅读全部产品、交互、视觉、字段、安全、验证和技术文档。

不要恢复旧版低保真的表单化页面，不要批量搭建全部页面。先检查现有项目结构与依赖，报告发现的冲突，然后只实现交接文档第 4 节规定的可操作纵向切片：

> 首页记录流 → 底部记录层与真实键盘 → `#作品名` 文本输入 → IndexedDB 自动保存与恢复 → 完成后回到原位置 → 记录卡 → 成品详情 → 个人态度与用户独立选择的推荐判断 → 查看／编辑／新增一张记忆卡片。

首轮使用本地假数据和确定性假分析，不接真实 AI、GitHub 或私人票务数据。必须复用 `docs/design/tokens-v2.css` 与 `docs/design/revision-02/` 的当前视觉方向，并在 412×915、360×800 的浅色／深色环境中验证。

特别注意：

- 隐藏、后移或合并页面不等于删除开发文档中的功能；
- 原始文字必须先本地保存，网络失败不得丢失；
- 首页壁纸主体和顶部安全层使用独立蒙版 token，不能用厚重白雾洗掉图案；
- 推荐值固定为“会／看对象／不会”，默认空，只能由用户选择，AI 不得推断；
- 不使用紫色、紫色渐变、玻璃拟态或通用 AI SaaS 模板；
- 首轮交付需包含运行说明、测试结果、Android 尺寸截图、未接入功能清单和下一阶段计划。
