# 电影印记：视觉审查说明 v2

状态：等待用户评审  
日期：2026-08-01

## 1. 本轮审查对象

本轮依据 [《以记录为中心的交互修订 v2》](../INTERACTION_DESIGN_REVISION_V2.md) 制作，不再沿用“六张后台表单”的旧结构。

| 编号 | 状态 | 主要验证问题 |
|---|---|---|
| 01 | 首次使用 | 电影／动画气质是否先于功能说明；入口是否足够单纯 |
| 02 | 日常记录流 | 二次元作品壁纸是否仍在；内容是否始终高于壁纸；“＋”是否稳定、拇指可达 |
| 03 | 随手记录 | 输入是否保持上下文；键盘上方是否像开放写作面而非表单 |
| 04 | 粘贴票务 | 是否做到粘贴即导入，不再让用户检查后台解析过程 |
| 05 | 个人态度与推荐 | 态度是否通过心理轴表达；推荐是否由用户独立选择并按条件展开 |
| 06 | 成品与记忆卡片 | 成品是否可直接阅读；记忆卡片是否真正像卡片而非清单 |

## 2. 结构变化

- “新建电影”改为当前记录流上的底部输入层；
- 电影名和影院优先通过 `#` 与自然文字表达；
- “检查场次”被删除，票务粘贴后自动进入后台；
- “AI 整理状态”被删除，状态留在记录卡片上；
- 五步确认工作台拆除，个人态度成为一次只做一个判断的聚焦层；
- 卡片类型库降级为编辑卡片时的二级能力；
- “最终预览与保存”被删除，成品详情就是结果，并自动保存。
- 被隐藏或后移的功能仍在 MVP 范围内；成果页保留编辑、添加卡片、导出与同步入口。

## 3. 视觉变化

- 主色从高饱和办公蓝改为偏青的石油蓝，避免蓝紫和 Material baseline 紫色；
- 中性底色略带温度，琥珀色只用于放映余光与强烈记忆；
- 首页卡片只承载真实记录，不再用卡片包裹每个字段模块；
- 两种首页状态都保留壁纸；有记录后按日从已绑定的 Bangumi 条目图片中轮换。用户评审后蒙版已减薄到仍能辨认海报图案的范围，记录卡本身保持不透明；
- 正文使用 17／29 左右的阅读尺度；
- 输入提示明确说明 `#` 的用途，不沿用 flomo 文案；
- 删除图片插入；完成动作改为输入区右下角的明确文字按钮；
- 个人态度的分析建议压缩为“文字倾向：喜欢”；
- 推荐判断合并到个人态度层下半部，但不由态度或 AI 自动推导；三项选择后按“会／看对象／不会”展开各自条件字段；
- 记忆卡片完整显示一张，不再截断下一张；成果页显示编辑、添加卡片和导出／同步入口；
- 不使用渐变、玻璃拟态、霓虹、发光和 AI 装饰图形。

## 5. 自动检查结果

- 412×915 与 360×800，浅色／深色共 24 张截图已成功渲染；
- 无水平或垂直页面溢出；
- 所有按钮触控范围不小于 44px，主要动作与常用工具为 46–56px；
- 主要正文、辅助文字和主动作颜色对比均超过 4.5:1；
- CSS 未使用渐变；
- 未包含 Material baseline 紫色色值。

## 6. 本轮不做的事

- 不实现生产前端页面；
- 不把静态键盘当作系统键盘实现；
- 不确定最终品牌插画与动效；
- 不扩展字段、卡片类型或同步范围；
- 不因样张存在而恢复被删除的中间确认页面。

## 7. 通过视觉后才进入的验证

视觉方向确认后，先制作两个可点击交互原型：

1. 首页 → “＋” → 键盘输入 → 收起并回到原位置；
2. 成品 → 个人态度心理轴 → 选择／撤销 → 返回成品。

这两个原型通过实际手机操作确认后，再开始最小垂直切片实现，不批量铺开全部页面。
