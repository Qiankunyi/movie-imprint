# 电影印记 Design Tokens v2

状态：交互修订后的视觉评审稿  
日期：2026-08-01  
依据：`VISUAL_DESIGN_DIRECTION_V1.md`、`INTERACTION_DESIGN_REVISION_V2.md`

## 1. 视觉意图

关键词：安静、私人、电影余韵、可长期阅读、拇指可达。

- 以偏青的深石油蓝替代 baseline Material 紫色和高饱和办公蓝；
- 大面积使用略带温度的中性灰白／炭黑，避免纯白后台和蓝色信息板；
- 琥珀色只代表放映灯光、被强烈击中的记忆或插画焦点，不作全局按钮色；
- 首页在内容层下保留二次元作品壁纸；使用固定蒙版降低对比，不使用会制造玻璃拟态的模糊卡片海洋；
- 不使用渐变、玻璃拟态、霓虹、发光边框和通用 AI SaaS 图形；
- 卡片只用于真实内容单位，不把每一组字段包成同形圆角容器。

## 3. 态度语义

态度首先靠空间位置、节点大小、标签和触觉反馈区分，颜色只作为辅助。

| 态度 | 结构语义 | 视觉响应 |
|---|---|---|
| 不喜欢 | 心理轴左端 | 最小偏左节点；短促反馈 |
| 无感 | 轴中心 | 中性空心节点；无扩张 |
| 喜欢 | 轴右侧 | 较大节点；选择后稳定展开 |
| 超喜欢 | 轴最右端 | 最大节点；使用少量 `film` 琥珀色 |
| 不好说 | 不属于强度轴 | 独立分支，使用双层／交叠轮廓表达复杂 |

不得把“不好说”排列在“超喜欢”后面，也不得预先选中 AI 建议。

推荐判断在态度轴下方使用独立的“会／看对象／不会”选择组。它不得继承态度选中状态，也不显示 AI 推荐值；选中后用一行摘要引出对应条件字段。

## 4. 字体

字体栈：Roboto、Noto Sans SC、Noto Sans JP、系统无衬线。

| Token | 字号／行高 | 字重 | 用途 |
|---|---:|---:|---|
| `display` | 28／36sp | 600 | 首次使用短句 |
| `title` | 22／30sp | 600 | 作品名、页面主标题 |
| `card-title` | 18／26sp | 600 | 记录与记忆卡标题 |
| `body-large` | 17／29sp | 400 | 输入与长文阅读 |
| `body` | 15／24sp | 400 | 卡片正文 |
| `label` | 13／18sp | 600 | 标签、动作、类型 |
| `meta` | 12／18sp | 500 | 时间与后台状态 |

正文不使用手写体、斜体或模拟引号装饰。

## 5. 间距、圆角与层级

基础间距：`4, 8, 12, 16, 20, 24, 32, 40dp`。

- 页面水平安全边距：16dp；长文详情为 20dp；
- 内容卡：16dp 圆角，仅用于一条完整记录或一张完整记忆；
- 底部输入层：顶部 24dp 圆角，下沿与键盘相接；
- 小标签：8dp 圆角；
- FAB：56dp 圆形，底部避让系统手势区 20–28dp；
- 阴影只区分悬浮层：浅色 `0 8px 24px rgb(13 32 37 / 10%)`；深色优先用明度差，不叠重阴影；
- 不给普通字段、标题和每个模块分别加容器。

## 6. 组件原则

### 6.1 首页记录卡

- 首次使用采用原创二次元电影视觉；已有记录后使用按日轮换的已记录作品海报；
- 壁纸主体蒙版以浅色约 44–54%、深色约 52–62% 为起点；顶部导航使用独立的较强安全层，记录卡保持不透明，避免为了可读性把整张壁纸洗掉；
- 一条记录一个内容单元；
- 先显示用户文字，时间和处理状态退后；
- 标签在正文语境中出现，不另建“标签区”；
- 卡片之间使用 12dp 间距，避免表格分割线列表感。

### 6.2 记录层

- 整个空白区域都是编辑器；
- placeholder 只有一层，不同时显示标题、解释和示例段落；
- 工具栏高 56dp，图标触控区至少 48dp；
- 完成动作使用右下角紧凑文字按钮，不使用含义不明的单独勾号，也不使用横跨全宽的 CTA；
- 不提供图片插入；MVP 的原始输入保持纯文字与标签；
- 保存状态只在发生失败或恢复时提升权重。

### 6.3 记忆卡片

- 推荐宽度为视口的 78–84%，下一张露出 12–18%；
- 正常卡片至少有“类型、标题、内容”三个阅读层级；
- 操作进入溢出菜单；默认不展示编辑、删除、排序、证据和关联字段；
- 核心卡片可用 `film` 色的小型标记，不使用星空或发光效果。

## 7. 动效

- 底部层进入／退出：220ms，标准强调缓动；
- 卡片横向吸附：180–240ms；
- 态度节点选择：160ms 位置与尺度响应；
- 保存成功不弹大型庆祝，只用一次轻触觉与低权重文字；
- 遵循系统减少动态效果；不使用循环动画、粒子和漂浮。

## 8. Android 与无障碍

- 设计基准：412×915dp，同时检查 360×800dp；
- 关键触控目标至少 48×48dp；
- 正文与背景对比度至少 4.5:1；非文字状态至少 3:1；
- 状态不得只靠颜色，必须同时使用文字、形态或位置；
- 背景延伸到 edge-to-edge，内容避开状态栏和手势区；
- 键盘出现时不遮挡工具栏、完成动作和当前输入行。
