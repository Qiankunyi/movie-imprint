# ADR-002：Bangumi 封面仅作为带来源标注的私人应用壁纸

日期：2026-08-02  
状态：已采纳

## 背景

C2 要求从已经确认 Bangumi subject ID 的作品中按日选择首页壁纸。Bangumi 正式 API 提供 `/v0/subjects/{subject_id}/image` 图片接口，并通过重定向返回条目图片。Bangumi 版权声明将封面包含在条目信息中，要求开发者使用 API 并遵守版权声明；已有版权作品仍按 Fair use 处理。

## 决策

1. 只通过正式图片 API 获取封面，不抓取条目页面，也不直接使用搜索响应中的外部图片 URL。
2. 浏览器只访问电影印记同源代理；代理只跟随到 `https://lain.bgm.tv`，验证图片类型并限制单张 6 MB。
3. 首页明确显示“来源 Bangumi”，链接到规范化的条目页。
4. 封面只用于钱坤一的私人、非商业应用界面，不写入感想记录、导出文件或 GitHub 同步资产。
5. 服务端最多内存缓存 12 张；Service Worker 最多离线缓存 12 张。
6. 没有已确认作品、没有图片、接口失败或离线未命中缓存时，使用仓库内现有中性壁纸。
7. 若未来公开发布或商业使用，必须重新核对图片权利与署名要求，不能沿用本 ADR 自动放行。

## 按日选择

- 候选只来自 `identity_status: matched` 且含 Bangumi ID 的 Work；
- 使用本地日期和排序后的 subject ID 集合进行确定性选择；
- 当天选择写入 IndexedDB `meta`，同一天新增作品不改变壁纸；
- 次日重新选择；无候选时不创建按日选择。

## 安全与隐私

- subject ID 必须为正整数；
- 重定向目标必须是官方 HTTPS 图片主机；
- 只接受 JPEG、PNG、WebP；
- 前端不接触 Bangumi token，也不接触 `lain.bgm.tv` 地址；
- 图片响应不包含私人记录内容。
